# Third-Party Component

## CPython 3.14.6 Embeddable Runtime for Windows, 64-bit

JC ScrapMap includes the official isolated CPython embeddable runtime so
players do not need to install Python.

- Publisher: Python Software Foundation
- Official file: `python-3.14.6-embed-amd64.zip`
- Official source:
  `https://www.python.org/ftp/python/3.14.6/python-3.14.6-embed-amd64.zip`
- Published SHA-256:
  `DF901E84A896FF1EE720AD03377E0C8D8C2244FDA79808AEEAFF6316DF1CB75C`
- License: Python Software Foundation License
- Included license: `runtime/python/LICENSE.txt`

The archive hash was verified before its files were added to this release.
JC ScrapMap does not modify the runtime or install it into Windows.
