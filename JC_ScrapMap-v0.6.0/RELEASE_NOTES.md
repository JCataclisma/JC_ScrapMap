# JC ScrapMap 0.6.0 — First Packaged Version

- Exact per-seed roads and water
- Read-only last-saved player position
- Map refresh while Scrap Mechanic remains open when save data is available
- Per-save custom notes
- Fixed POI/anchor spoiler layer
- Local browser interface with pan, zoom, grid, and scale
- Managed, hash-verified road-helper recovery
- No analytics, uploads, or remote services
- Self-contained private runtime; no Python installation required

Field testing reported that the player-position refresh and existing map
refresh work very satisfactorily without closing Scrap Mechanic.
